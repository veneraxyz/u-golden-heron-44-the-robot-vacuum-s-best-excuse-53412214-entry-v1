Entry for the make.fun competition **"The Robot Vacuum's Best Excuse"** — one line, the funniest excuse a robot vacuum gives for missing a spot.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Writes exactly one line (max 140 characters) to `entry.txt`, with a trailing newline. Standard library only, plain TypeScript.
